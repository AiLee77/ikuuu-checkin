# ikuuu 自动签到 (多账号 / GitHub Actions)

基于 Python 与 GitHub Actions 实现的 ikuuu 机场自动签到脚本。通过直接携带 Cookie 进行签到，完美避开登录阶段的行为验证码；敏感账号凭证托管于 GitHub Secrets，代码完全开源也能保障个人账号隐私安全。

---

## ✨ 项目特性

- **避开人机验证**：采用已登录会话的 Cookie 机制直接请求打卡接口，无惧极验 / Cloudflare 5秒盾拦截。
- **支持多账号批量**：单脚本顺序遍历打卡，自动分配动态序号（`账号 #01`、`账号 #02` 等）并进行邮箱信息脱敏。
- **详细信息回显**：实时打印每个账号的签到状态、签到获取的流量奖励以及当前剩余流量。
- **拟人化防风控**：支持启动前全局随机延迟，并支持设置账号间的随机休眠间隔。
- **零成本云端运行**：基于 GitHub Actions 定时执行，借助海外官方云端环境，避免国内直连域名被阻断。
- **配置与数据完全解耦**：
  - 网站全局配置（域名、休眠间隔）独立存放于 `config.json`；
  - 账号凭据严格隔离存放于 GitHub Secrets（本地开发时存放于未被版本控制的 `accounts.json`）。

## 🚀 快速上手指南

### 步骤 1：Fork 本仓库

点击仓库右上角的 **Fork** 按钮，将本仓库完整复制到您自己的 GitHub 账号下。

---

### 步骤 2：获取账号 Cookie

由于目前登录页面强制启用了行为滑块验证码，最稳定省心的方式是提取浏览器登录后的会话 Cookie：

1. 使用电脑浏览器打开并登录您的 ikuuu 账号，进入个人中心仪表盘页面（确保能看到流量统计卡片）。
2. 在键盘上按下 `F12` 打开开发者工具，切换到 **网络 (Network)** 选项卡。
3. 按 `F5` 刷新网页，点击请求列表顶部的第一个记录（通常名为 `user` 或网站主域名）。
4. 在右侧面板中依次点击 **标头 (Headers)** -> **请求标头 (Request Headers)**，找到 **`Cookie:`** 这一项。
5. 复制整行 Cookie 内容（格式类似于：`email=...; expire_in=...; ip=...; key=...; PHPSESSID=...; uid=...`）。

> 💡 **提示**：若需要配置多个账号，可以利用浏览器的“无痕/隐私窗口”或者多个不同的浏览器分别登录，依次将每个账号的完整 Cookie 复制保存。

---

### 步骤 3：在 GitHub Secrets 中配置账号信息

为确保您的账号资产安全，切勿将 Cookie 提交到任何公开代码文件中。请在 GitHub Secrets 中统一注入：

1. 进入您 Fork 后的 GitHub 仓库页面，点击顶部的 **Settings** 选项卡。
2. 在左侧侧边栏中找到 **Security** -> **Secrets and variables**，展开后点击 **Actions**。
3. 点击页面中的绿色按钮 **New repository secret**：
   - **Name** 严格填写：`IKUUU_ACCOUNTS`
   - **Secret** 填入标准 JSON 数组内容（支持任意数量的账号）：

```json
[
  {
    "cookie": "在此粘贴账号1的完整Cookie"
  },
  {
    "cookie": "在此粘贴账号2的完整Cookie"
  }
]
```

4. 点击 **Add secret** 保存。

---

### 步骤 4：启用 Actions 工作流并测试

1. 点击仓库顶部的 **Actions** 标签页。
2. 如果页面提示工作流已被禁用，请点击绿色的 **I understand my workflows, go ahead and enable them** 按钮激活。
3. 在左侧工作流列表中找到并选中 **ikuuu Checkin**。
4. 点击右侧的 **Run workflow** 下拉菜单，再点击绿色的 **Run workflow** 按钮手动触发一次运行。
5. 等待几十秒后刷新页面，点击查看最近的构建日志，确认各个账号状态输出为 `成功` 或 `今日已签` 即可。

## ⚙️ 配置文件说明 (`config.json`)

如果后续机场更换了镜像域名或需要微调请求间隔，直接在网页上编辑根目录下的 `config.json` 即可：

```json
{
  "base_url": "https://ikuuu.top",       // 机场最新可用域名（更换域名直接在此修改）
  "start_random_delay_max": 60,          // 启动前最大随机等待秒数（0 表示立即执行）
  "interval_min": 3,                     // 账号间最小休眠等待秒数
  "interval_max": 8                      // 账号间最大休眠等待秒数
}
```

## ⏰ 定时签到时间规则

工作流文件位于 `.github/workflows/checkin.yml`，默认采用 UTC 时间标准设置：

```yaml
- cron: '0 13 * * *'
```

- **执行频率**：每天一次。
- **触发时间**：UTC 时间 13:00，换算即为 **北京时间每天 21:00**。
- *注：GitHub Actions 的定时触发属于分布式排队调度，实际启动时间出现几分钟的自然漂移属于正常现象。*
